# MM333-Week4_Mediation-moderation
R scripts for mediation and moderation analysis: visualizing relationships, testing indirect effects, interaction effects, and moderated mediation with reproducible code and output.

## What's included
- `analysis.R`: main script for mediation and moderation analysis
- `output/`: tables and figures generated by the script
- `recommendations/`: data-driven recommendations for the managers based on the analysis

## Methods
- **Mediation:** tests whether the effect of X on Y operates through a
  mediator M (indirect effect, with bootstrapped confidence intervals)
- **Moderation:** tests whether the effect of X on Y depends on a
  moderator W (interaction term, simple slopes)
